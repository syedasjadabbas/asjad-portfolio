EduCart

A full-stack MERN student e-commerce platform featuring product search and filtering, cart, PayPal checkout, order tracking, wishlist, student discounts, and role-based admin dashboard with sales analytics.

Role Developer
Category E-Commerce & Web Applications
Timeline Academic Project · 2026
Core Stack React.js · Node.js · Express · MongoDB · JWT · Tailwind CSS

Problem & Challenge

Online student commerce platforms need to provide seamless browsing, trusted checkout flows, and accessible customer support while keeping administrative tools secure and easy to manage.

The goal was to build a complete student e-commerce application with intuitive catalog exploration, reliable payment processing, authenticated order history, wishlist management, and an administrative control panel providing sales analytics and product management.

Technical Approach & Architecture

The application is built on the classic MERN stack. A React.js (Vite) single-page application styled with Tailwind CSS provides the user interface, communicating via REST endpoints with a Node.js and Express backend. MongoDB stores product records, user accounts, and purchase orders.

MERN Application Architecture & Data Flow
React (Vite) UI
Interactive catalog filtering, cart state, wishlist, and student discount applications
↓
Express REST API Gateway
Authenticates requests, enforces role-based access control, validates payload schemas
↓
PayPal SDK & External Integrations
Handles transaction checkout, Cloudinary media hosting, and Nodemailer email receipts
↓
MongoDB Database Store
Persists products, order records, user profiles, and operational logs

Stateless JWT authentication protects private endpoints, allowing regular users to track personal orders while reserving analytics and catalog modifications strictly for admin accounts.

Key Features & Implementation

1. Authentication & Role-Based Access Control

Implemented secure JWT authentication with password hashing using bcrypt. Middleware layers intercept incoming requests, validating bearer tokens and verifying roles before allowing access to administrative routes or personal customer orders.

2. Integrated Checkout & Service Layer

Integrated PayPal payment processing to provide a secure checkout flow. Media uploads for products are managed through Cloudinary for optimized asset delivery, and Nodemailer handles automated email confirmations and status updates. The platform also includes a rule-based support chatbot to guide visitors through common queries.

Deployment & Production Notes

The frontend application is deployed on Vercel for global edge delivery and fast static asset caching. The backend Node.js and Express server runs on Render, connected to a managed MongoDB cluster.

Lessons Learned

Building a full MERN application provides end-to-end control over data modeling, authentication pipelines, and third-party API integration. Separating concerns across clear middleware boundaries ensures maintainable code and robust security enforcement.
